# 数学科目出题与排版规范 (Math Exam Rules)

1. **题型划分与靶向标注：**
   - 题目必须按考点分类（如：一、正负数实际应用；二、规律探索；三、代数式化简；四、行程实际应用；五、压轴几何/最值探究）。
   - 每小题必须配有具体分值及靶向原题说明（如 `(对应第19题)`）。

2. **解答题排版：**
   - 计算与解答题下方强制预留 6-10 行空白答题区，并标注 `【请在此区域书写解题过程】`。
   - 几何证明题须在答题区上方预留作图位，并注明「（如需辅助线，请在图上标出）」。

3. **公式规范：**
   - 必须使用标准 Word/LaTeX 数学公式语法（如 `$x^2$`、`$\frac{a}{b}$`、`$|x+3|$`），确保导出的 Word 文档中公式不乱码。
   - 若目标格式为纯 Markdown 且渲染器不支持 LaTeX，退化为 Unicode/纯文本写法（如 `x²`、`a/b`），并在卷首说明。

4. **数据合理性：**
   - 应用题数据须符合生活常识（人数为正整数、价格保留两位小数、速度单位一致）。
   - 计算结果尽量为整数或有限小数，避免无理数作为最终答案（除非考点本身要求）。
