# 全局排版与交付铁律 (Global Print Rules)

## 1. 卷头标准规范
- **主标题：** [年级科目][单元/卷名，例如：错题强化训练测试卷]
- **副标题（可选）：** 标注靶向特训目标（例如：“针对薄弱题型（第3、9、19题同类型）进行深度靶向特训”）
- **缺教材兜底标注：** 若本次出题未挂载原版教材 PDF，副标题必须追加一行：
  `（本卷依据[版本][年级][章节]通用考点生成，未挂载原版教材，建议家长核对范围）`
- **学生信息栏：** 统一采用双端对齐三要素：

  学校：______________　　班级：______________　　姓名：______________　　得分：______________

## 2. 页脚与页码硬性要求
- **格式：** 每页底部必须包含两侧信息：
  - **左下角：** 国学/劝学名句（随机换，如：“学而不思则罔，思而不学则殆”、“博学而笃志，切问而近思”）。
  - **右下角：** 精确标注页码 `第 X 页 / 共 Y 页`。

## 3. 答题空间与大题结构
- **大题标题：** 每个大题模块必须带靶向说明，如：`一、零件合格率与正负数的实际应用(对应第3题)`。
- **分值标注：** 每小题必须在题号后标注分值，如 `1.（3分）……`。
- **解答题留白：** 所有计算题、应用题、几何证明题下方，必须生成高 6-10 行的答题框：

  ┌────────────────────────────────┐
  │ 【请在此区域书写解题过程】         │
  │                                │
  │                                │
  │                                │
  │                                │
  │                                │
  │                                │
  └────────────────────────────────┘

  实现方式：Word 用 1×1 表格或带边框段落；Markdown 用引用块 + 空行。目标是可打印、留白充足。
- **选择题 / 填空题：** 不留大块答题框，仅需下划线或括号，避免浪费纸张。
- **同一小题不得跨页断开。**

## 4. 答案与解析后置（硬性）
- 所有参考答案与解析**强制放在文档最末页**，正文只保留题目。
- 末页以独立分页开始，标题为 `参考答案与解析`。
- 解析须包含三项：**答案 → 关键步骤 → 易错点提示**。

## 5. 通用版式
- 字体：中文宋体/黑体，英文 Times New Roman；正文小四（12pt），大标题加粗居中。
- 页边距：上下 2.5cm、左右 2cm，保证 A4 可打印。
- 行距 1.5 倍，段前段后各 0.5 行。
- 目标机器无宋体/黑体时退化为系统中文字体（macOS 可用 Songti SC / PingFang SC），保证不乱码即可。

## 6. 跨科合卷（多科目放同一份卷时适用）
- **板块化**：卷内按科目分板块，板块标题形如 `【数学】一、一元一次方程`。
- 每个板块内部**遵守该科目的分科规则**（如英语禁听力、数学留草稿框、语文防超纲）。
- 卷头副标题须写明覆盖科目与薄弱点类型，例：
  `错题靶向重练卷（数学+英语 ｜ 覆盖 运算失误、语法时态 等 5 个薄弱点）`
- **答案按科目分节**后置，末页标题 `参考答案与解析`，下分
  `【数学】`、`【英语】`、`【语文】` 小节。
- 页脚、页码、答题框等全局铁律对合卷同样生效。
