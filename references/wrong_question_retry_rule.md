# 错题变式重练、批量组卷与靶向特训规则 (Wrong Question Retry Rules)

## 1. 变式核心原则（"换汤不换药"）
- **严禁直接照抄原题**：必须提取原题的核心知识点与考点模型。
  - 例：原题是行程相遇问题，变式可换成工程合作或水流航行，但底层方程逻辑完全一致。
- **数值与情境改变**：更改已知数据、人名、物品或生活情境，防止学生靠记忆直接写答案。
- **同类型判定**："同类型"= 同一 `knowledge_tag`（知识点标签），不是同一题型名称。

## 2. 变式数量 (Variant Count)
- 每个错题生成的变式数量记为 **N**。
- 指令说「每个出三个 / 出三道同类型」→ **N=3**；说「出 N 个」→ 取该数字。
- 指令未指定数量 → **N=1**（一道错题配一道变式）。
- 同一道错题的 N 个变式之间**也必须互不相同**，不得只是换个数字就重复。

## 3. 错题关联与靶向标注
- 变式卷标题必须明确标注针对性，例：
  `针对薄弱题型（对应第3、9、19题同类型）进行深度靶向特训`
- 题目编号及小题下方**必须显式标注**关联的原错题编号，如：
  `(对应错题库 W20261028-001)`
- 同一原错题的多个变式用 `-1 / -2 / -3` 后缀区分，例：
  `(对应错题库 W20261028-001-2)`

## 4. 筛选与范围（合卷时的取题口径）
- **时间筛选**：按 `date` 字段。
  - 「今天」→ 当日；「最近一个月」→ 近 30 天；「最近 N 天」→ 近 N 天；未指定 → 不限时间。
- **状态过滤**：默认只取 `mastery_status ≠ 已掌握`；家长说「所有错题」时不过滤。
- **科目范围**：默认单科；说「所有科目 / 全部科目 / 放在一起」时跨科合并。
- 筛选后若**没有任何符合条件的错题**，明确告知家长，不要用凭空编造的题充数。

## 5. 分类维度（全学科统一）
每道错题必须带两个统一字段，这是跨科归类与组卷的唯一依据：

- `knowledge_tag` — 知识点标签，例：`一元一次方程-移项`、`英语-一般过去时`、`语文-古诗文默写`
- `error_type` — 错误类型，统一枚举（六选一）：
  - `概念理解错误`
  - `运算计算失误`
  - `审题偏差`
  - `答题不规范`（格式/步骤缺失）
  - `知识遗忘`（学过后遗忘）
  - `超纲未掌握`

**组卷原则**：优先把相同 `error_type` 的变式编在同一个大题内，便于集中突破同一类毛病。
分科的 `subject_specific_data` 作为可选扩展保留，不参与跨科统计。

## 6. 跨科合卷
- 涉及多科目时合并为**同一份卷**，卷内按科目分板块，标题形如 `【数学】一、一元一次方程`。
- 每个板块遵守该科目分科规则。
- 答案**按科目分节**统一后置到最末页。
- 排版细节见 `00_global_print_rules.md` 第 6 节。

## 7. 智能归档与状态更新
变式卷生成并导出后，必须自动更新 `wrong_questions.json`：
- 所有被用到的错题 `review_count` +1。
- 家长反馈变式已做对 → `mastery_status` 从「待复习」改为「已初步掌握」。
- 新归档错题必须补齐 `knowledge_tag` 与 `error_type`，缺失则本次补填。
