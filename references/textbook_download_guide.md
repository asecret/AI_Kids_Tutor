# 教材自动下载操作规程 (Textbook Download Guide)

本文件是 `SKILL.md` 步骤 0 第 3 步的执行细则。
目标：依据学生档案的「学段 + 科目 + 年级 + 学期 + 版本」，从开源教材库
`TapXWorld/ChinaTextbook`（GitHub）取得对应教材 PDF。

## 0. 铁律

- **必须真的去尝试下载**，不允许以任何理由直接跳过。
- **不要事先询问用户要不要下载** —— 直接执行，完成后汇报结果。
- **严禁 `git clone` 整个仓库**（GB 级）。只取单本文件。

## 1. 仓库结构（三段不一致，必须逐级列目录发现）

| 学段 | 顶层目录 | 年级子目录 | 版本目录形态 | PDF 位置 |
| --- | --- | --- | --- | --- |
| 小学 | `小学` | **无** | `人教版`、`统编版`（不带出版社后缀） | 直接在版本目录下 |
| 初中 | `初中` | `七年级` / `八年级` / `九年级` | `人教版-人民教育出版社`（**带出版社后缀**） | 年级子目录下 |
| 高中 | `高中` | **无** | `人教版（A版）（主编：…）-人民教育出版社` | 直接在版本目录下 |

> ⚠️ 三段结构各不相同，**严禁凭空拼接路径**。
> 必须用 GitHub API 逐级列目录，以实际返回为准。

## 2. 关键映射（档案说法 → 仓库实际名称）

| 档案里的说法 | 仓库里叫什么 |
| --- | --- |
| 初一 / 初二 / 初三 | 七年级 / 八年级 / 九年级 |
| 语文「部编版」「人教版」 | `统编版`（小学）／ `统编版-人民教育出版社`（初中） |
| 英语「外研版」 | `外研社版-外语教学与研究出版社` |
| 数学「人教版」 | `人教版`（小学）／ `人教版-人民教育出版社`（初中） |
| 学期「上册 / 下册」 | 文件名中含 `上册` / `下册` |

**匹配规则**：版本目录名**包含**档案里的版本关键词即算命中
（如档案「人教版」可匹配 `人教版-人民教育出版社`）。

## 3. 列目录（发现真实路径）

用 GitHub Contents API 逐级列目录，路径中的中文需 URL 编码：

```bash
curl -s "https://api.github.com/repos/TapXWorld/ChinaTextbook/contents/<已URL编码的路径>"
```

返回 JSON 数组，每项含 `name` / `path` / `sha` / `size` / `type` / `download_url`。
按第 1 节表格逐级往下找，直到定位到 `.pdf` 文件，记下它的 `sha` 与 `size`。

> 若出现多个候选版本（如小学英语有一年级起点 / 三年级起点等多种），
> **列出候选请用户确认，不要猜**。

## 4. 下载（推荐通道）

⚠️ `raw.githubusercontent.com` 在国内网络常被阻断（实测直连返回空 / 超时）。
**优先使用 GitHub API 的 blob 通道**（走 `api.github.com`，实测可用）：

```bash
curl -sL --max-time 300 \
  -H "Accept: application/vnd.github.raw" \
  -o "<保存路径>.pdf" \
  "https://api.github.com/repos/TapXWorld/ChinaTextbook/git/blobs/<sha>"
```

`<sha>` 来自第 3 步列目录返回的 `sha` 字段。

备选（blob 通道不通时）：

- `download_url` 字段（即 raw.githubusercontent，国内多半不通）
- 给家长浏览器链接自行下载：
  `https://github.com/TapXWorld/ChinaTextbook/blob/master/<path>`

## 5. 下载后校验（必做）

1. **文件头**：必须是 `%PDF-`。不是则判为失败，删除重来，**不得使用损坏文件**。
2. **大小一致**：与列目录返回的 `size` 比对。
   - 不一致或明显偏小 → 说明**下载被截断**（大文件常见），判为失败，
     转 `SKILL.md` 步骤 0 第 4 步。
3. **分片文件**：高中部分教材是分片保存的（`.pdf.1`、`.pdf.2` …），
   需**按序号 `cat` 合并**成一个 `.pdf` 后再做上述校验。

## 6. 已知限制

- 小学教材单本可达 **50 MB**，弱网下极易超时。最多重试 1 次，
  仍失败就降级并给家长手动下载链接，不要反复重试。
- GitHub API 未认证时有限流（约 60 次/小时）。列目录层级不多，正常够用。
- 若仓库结构日后变更，以**逐级列目录的实际结果**为准，本文件表格仅作参考。

## 7. 成功后

按 `SKILL.md` 步骤 0 的命名规范重命名（`科目_年级学期_版本.pdf`）→
存入 `./textbooks/` → 写入 `manifest.json` → 回到步骤 0 第 2 步做四维匹配。
